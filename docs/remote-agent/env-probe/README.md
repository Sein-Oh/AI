# 원격 에이전트 환경 진단 스킬

팀원이 만든 원격 에이전트(브라우저 접속, 스킬 = 이름 + 한 줄 설명 + 지시문 + 업로드한 스크립트)에서
스킬 스크립트가 어디서, 어떤 파이썬 환경으로 실행되는지와 로컬 MCP로 연결한 파일을 스크립트가 읽을 수 있는지 확인합니다.
결과를 보고 reader, ml-kit을 그 에이전트용 스킬로 옮길지 정합니다.

## 스킬 등록
- 이름: `env-probe`
- 한 줄 설명: 스킬 스크립트 실행 환경 점검
- 업로드 파일: `probe.py`
- 지시문 (그대로 붙여 넣기):

```text
사용자가 "환경 점검" 또는 "env-probe"를 요청하면 업로드된 probe.py를 파이썬으로 1번 실행한다.
사용자가 파일이나 폴더 경로를 주면 그 경로들을 인자로 붙인다. 예: python probe.py "C:\gemma_test\공정.csv"
출력된 JSON 한 줄을 고치거나 요약하지 말고 그대로 사용자에게 보여 준다.
스크립트를 실행할 수 없으면, 어떤 오류가 났는지와 스크립트를 어디서 실행하려 했는지 그대로 알린다.
```

## 시험 순서
1. 경로 없이 실행: 운영체제, 파이썬, 라이브러리, 실행 폴더 확인
2. 로컬 MCP로 연결한 폴더의 파일 경로를 주고 실행: `files[].readable`이 true인지 확인
3. 결과 JSON 두 개를 Claude에게 전달

## 결과 보는 법
| 항목 | 의미 |
|---|---|
| `is_windows`, `os` | 스크립트가 사용자 PC에서 도는지(Windows, 사용자 이름) 서버에서 도는지 |
| `c_cli_exists` | true면 사용자 PC에서 실행된 것. `C:\CLI` 도구를 그대로 부를 수 있음 |
| `packages` | 서버에서 돈다면 reader(pymupdf, python-docx, openpyxl, olefile), ml-kit(pandas, scikit-learn, matplotlib)을 옮길 수 있는지 |
| `files[].readable` | 로컬 MCP 파일을 스크립트가 직접 읽을 수 있는지 (false면 파일을 에이전트가 따로 넘겨야 함) |
