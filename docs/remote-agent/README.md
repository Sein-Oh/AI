# 팀원 원격 에이전트에 도구 붙이기 (run.py 실행기 방식)

팀원 에이전트(브라우저 접속)의 스킬은 "이름(호출 명령) + 한 줄 설명 + 지시문 + 업로드 스크립트"로 만들고,
업로드 스크립트는 내 PC에서 MCP에 포함된 파이썬으로 실행됩니다 (env-probe로 확인).
도구는 `C:\CLI`에 하나만 두고, 스킬에는 실행기 `run.py`만 올립니다. run.py가 WinPython으로 `C:\CLI` 도구를 실행하고
결과 JSON 1줄만 돌려줍니다. OpenCode와 같은 도구, 같은 캐시, 같은 오류 로그를 씁니다.

## 스킬 2개 만들기
| 스킬 이름 | 한 줄 설명 | 지시문 | 업로드 |
|---|---|---|---|
| `ml-kit` | 표 데이터로 예측 모델 학습, 예측, ML 결과 보고서 | `ml-kit_지시문.md` 내용 전체 | `run.py` |
| `office-cli` | Excel/Word/PPT 읽기·쓰기, 문서 등록과 근거 검색, 되돌리기 | `office-cli_지시문.md` 내용 전체 | `run.py` |

- `run.py` 2행의 WinPython 경로(`C:\WPy64-313130\python\python.exe`)가 본인 PC와 다르면 고칩니다.
- 첫 시험: `office-cli` 스킬로 "등록된 문서 목록 보여줘" -> `reader.py list` 결과가 나오면 연결된 것입니다 (파일을 바꾸지 않음).

## 확인할 것
- 지시문은 "파일 쓰기 도구로 UTF-8 파일(.csv, .md)을 만든 뒤 --file로 넘긴다"를 전제로 합니다 (표, 여러 줄 글).
  팀원 에이전트가 내 PC에 파일을 쓸 수 없으면 엑셀 표 쓰기, 워드 여러 줄 쓰기가 막힙니다. 그때 알려 주면 run.py가 내용을 받아 파일로 만드는 방식을 추가합니다.
- 학습과 보고서(best 재학습)는 몇 분 걸립니다. 플랫폼의 스크립트 시간 제한이 짧으면 알려 주세요.

## 갱신
- 도구가 바뀌어도 `C:\CLI`만 반입하면 됩니다. 업로드한 run.py는 그대로입니다.
- SKILL.md가 바뀌면 지시문도 다시 붙여 넣어야 합니다. 지시문은 `python docs/remote-agent/build.py`로 SKILL.md에서 다시 만듭니다.
