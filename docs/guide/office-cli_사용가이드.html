office-cli 사용 가이드

엑셀, 워드, 파워포인트, 아웃룩, 문서 검색을 AI 에이전트(Gemma)에게 말로 시키는 방법 | 베타테스트용 | office-cli 1.4.6

office-cli는 에이전트가 Office 문서를 직접 읽고 고칠 수 있게 해 주는 도구입니다. 채팅에 하고 싶은 일을 평소 말투로 쓰면 에이전트가 알맞은 도구를 골라 실행하고 결과를 알려 줍니다. 이 가이드는 채팅에 무엇을 어떻게 쓰면 되는지를 사례로 보여 줍니다. 요청 예시의 "복사" 버튼으로 가져가 파일 이름과 값만 바꿔 쓰세요.

1. 이렇게 요청하세요

1.1 할 수 있는 일

엑셀

표 읽기, 값과 수식 넣기, 차트 만들기, 서식 꾸미기, 찾아 바꾸기, 시트 추가, CSV/PDF로 저장

워드

목차·장절·쪽 단위로 읽기, 내용과 그림 넣기, 찾아 바꾸기, 검토 메모 달기, 변경 추적 기록 보기, PDF 저장

파워포인트

슬라이드 읽기, 새 슬라이드 만들기(글머리, 카드, 그림, 표), 발표자 노트 읽기·쓰기, 순서 바꾸기, PDF 저장

앱 사이 옮기기

엑셀 차트를 워드/PPT에 그림으로, 엑셀 표를 워드/PPT 표로, 워드/PPT의 표·글을 엑셀로

아웃룩

보고 있는 메일 읽기, 메일 찾기, 답장 초안, 새 메일 초안 (보내기는 분명히 요청할 때만)

문서 검색

PDF, HWP, 워드, 엑셀 등을 등록해 두고 단어를 찾으면 "어느 파일 몇 쪽, 몇 장 몇 절"인지 근거와 함께 알려 줌

되돌리기

도구가 문서를 고치기 전에 자동으로 저장해 둔 지점으로 되돌리기

1.2 요청 문장의 기본 틀

요청 한 문장에 아래 네 가지가 들어 있으면 에이전트가 되묻지 않고 바로 실행합니다.

요소쓰는 법예
어느 문서열려 있으면 "열린 엑셀", "지금 보고 있는 워드". 닫혀 있으면 전체 경로. 같은 앱 문서가 여러 개 열려 있으면 파일 이름열린 엑셀 / C:\업무\보고서.docx / 월간보고.xlsx
어디시트, 셀 범위, 장절 번호, 쪽, 슬라이드 번호, 기준이 되는 문구Sheet1 A1:D20 / 2.1절 / 5쪽 / 3번 슬라이드 / "시험 결과" 제목 뒤
무엇을읽기, 넣기, 바꾸기, 만들기, 옮기기, 찾기읽어줘 / 넣어줘 / 바꿔줘 / 만들어줘
어떻게 (선택)결과물의 모양, 이름, 색, 저장 위치꺾은선, 제목은 월별 매출 / navy 테마 / C:\업무\결과.pdf 로

열린 엑셀 Sheet1 A1:B13으로 꺾은선 차트 만들어줘. 제목은 월별 생산량

파일의 전체 경로 복사하기: 탐색기에서 대상 파일을 마우스 오른쪽 버튼으로 클릭하고 "경로로 복사"를 누른 뒤, 채팅에 붙여 넣으세요. 경로 앞뒤에 따옴표가 함께 붙어도 괜찮습니다.

1.3 요청을 잘하는 요령

요령좋은 예아쉬운 예
대상을 분명히"열린 엑셀의 Sheet1 A1부터", "C:\업무\보고서.docx""그 파일", "아까 거"
범위를 구체적으로"A1:D20 읽어줘", "2.1절만 읽어줘""앞부분 좀 봐줘"
한 번에 한 가지씩"표 넣어줘" 다음에 "차트 만들어줘"표, 차트, 서식, 메일까지 한 문장에
결과물 모양을 말하기"꺾은선 차트, 제목은 월별 매출""보기 좋게 해줘"
표나 긴 글은 채팅에 그대로 붙여 넣기요청 다음 줄부터 표·목록을 붙여 넣기 (쉼표나 탭으로 칸 구분)"메일에 있는 그 표"(에이전트가 볼 수 없는 곳)
덮어쓰기·삭제·발송은 말로 분명히"기존 노트를 바꿔줘", "보내줘""알아서 정리해줘"

긴 대화를 이어 가면 에이전트가 앞 내용을 헷갈릴 수 있습니다. 작업 하나가 끝나면 새 대화에서 다음 요청을 시작하세요.

1.4 에이전트의 답에 이어서 말하기

에이전트의 답뜻이렇게 답하세요
완료 "~했습니다"도구가 작업 후 다시 읽어 확인까지 마침마음에 들지 않으면 "방금 한 거 되돌려줘"
확인 못함실행은 됐지만 결과를 다시 읽어 보지 못함문서를 직접 확인
후보 선택 "[후보] a, b"같은 이름·문구가 여러 곳이라 추측하지 않고 멈춤"2번", "Sheet2로"처럼 하나 고르기
진행 확인 "진행할까요?"삭제, 덮어쓰기, 새 시트, 메일 발송처럼 되돌리기 어려운 일대상을 확인하고 "예" 또는 "아니오"
실패파일이 없거나 값이 잘못됨안내에 따라 요청을 고쳐 다시. 이해되지 않으면 그대로 피드백(11장)

1.5 도구가 알아서 지키는 것

  • 고치기 전에 자동 저장 지점: 엑셀·워드·PPT를 고치기 전에 사본을 만들어 둡니다(문서마다 최근 5개).
  • 덮어쓰지 않음: 같은 이름의 파일이 있거나 열려 있으면 이름 뒤에 시각을 붙인 새 파일로 저장하고 알려 줍니다. 기존 시트나 노트를 바꾸는 일은 허락할 때만 합니다.
  • 추측하지 않음: 없는 시트에 쓰라고 하면 새 시트를 몰래 만들지 않고 묻습니다.
  • 메일은 초안까지만: "보내줘"라고 분명히 말하지 않으면 작성 창만 띄웁니다.
  • 읽기는 화면을 건드리지 않음: 시트, 스크롤, 슬라이드 위치가 그대로입니다.

2. 엑셀

엑셀 작업은 지금 보고 있는 통합문서가 기본 대상입니다. 다른 열린 문서는 이름으로, 닫힌 파일은 전체 경로로 알려 주세요.

2.1 내용 읽기, 찾기, 행 수 세기

열린 엑셀의 표 읽기

이럴 때: 표 내용을 요약하거나, 특정 값을 확인하고 싶을 때

열린 엑셀 A1:F30 읽고 어떤 내용인지 요약해줘

C:\업무\매출현황.xlsx 의 2024 시트 내용 보여줘

표 내용과 행 수를 알려 주고, 요청에 따라 요약합니다. 화면은 움직이지 않습니다.

특정 글자가 어디 있는지 찾기

열린 엑셀에서 "미입고"가 들어간 칸 찾아줘

그 글자가 든 칸의 주소(예: Sheet1!D14)와 값을 알려 줍니다.

CSV 파일 읽기, 행 수 세기

C:\업무\주문내역.csv 몇 행인지 세줘

엑셀 없이 파일을 읽어 행 수를 알려 줍니다. 한글 인코딩(UTF-8, CP949)도 자동으로 맞춥니다.

시트와 차트 구성 보기

열린 엑셀에 시트가 몇 개고 각각 어디까지 데이터가 있는지 알려줘

시트별 사용 범위와 차트 목록을 알려 줍니다.

2.2 표 입력하기

대화창에 적은 표를 엑셀에 넣기

열린 엑셀 A1부터 이름, 부서, 점수 표 넣어줘. 홍길동, 생산1팀, 90 김철수, 품질팀, 85 이영희, 생산2팀, 92

에이전트가 표를 파일로 정리한 뒤 엑셀 A1부터 넣고, 넣은 범위를 다시 읽어 확인합니다.

엑셀이나 메모장에서 복사한 표를 그대로 붙여 넣어도 됩니다. 쉼표나 탭으로 칸이 나뉘어 있으면 됩니다.

기존 표 아래에 이어 붙이기

열린 엑셀 표 맨 아래에 박민수, 생산1팀, 88 추가해줘

표의 마지막 행 다음 줄에 이어서 씁니다. 머리글은 다시 쓰지 않습니다.

다른 시트나 새 시트에 넣기

요약 시트 B2부터 이 표 넣어줘 (항목, 수량 / 볼트, 120 / 너트, 80)

"집계"라는 새 시트를 만들어서 A1부터 넣어줘

있는 시트면 바로 넣습니다. 없는 시트 이름을 말하면 새로 만들지 묻고, "새로 만들어"라고 답해야 만듭니다.

01234 같은 앞자리 0 코드, 15자리가 넘는 번호, 1-2처럼 엑셀이 날짜로 바꿔 버리는 글자는 도구가 글자 그대로 넣습니다.

2.3 수식 넣기

한 칸 또는 여러 칸에 수식

열린 엑셀 D2:D50에 =B2*C2 수식 넣어줘

범위 전체에 넣고 행 번호는 자동으로 맞춰집니다(D3은 =B3*C3).

절대참조($)가 들어간 수식

E2:E50에 =D2/$D$51 수식 넣어줘

$ 표시가 사라지지 않게 그대로 넣습니다.

계산용 표를 수식으로 만들기

열린 엑셀 A1:B101에 x와 sin(x) 표를 수식으로 만들어줘. x는 0부터 4π까지 100칸으로

머리글과 열마다 수식을 넣어 표를 만듭니다. 이어서 차트를 요청하면 그래프가 됩니다.

2.4 차트 만들기

범위로 차트 만들기

열린 엑셀 A1:B13으로 꺾은선 차트 만들어줘. 제목은 월별 생산량

A1:D6으로 세로 막대 차트 만들어줘. 제목은 팀별 실적

데이터 오른쪽 빈 곳에 차트를 만들어 다른 데이터를 가리지 않습니다. 이어서 워드나 PPT로 옮길지 제안하기도 합니다.

말할 때차트 종류
세로 막대 / 가로 막대막대 차트
꺾은선 / 표식 있는 꺾은선선 차트
원형파이 차트
영역영역 차트
분산형 / 분산형 선x-y 산점도
혼합 (막대+선)콤보 차트

차트 목록 보기, 지우기

열린 엑셀에 있는 차트 목록 보여줘

"팀별 실적" 차트 지워줘

2.5 서식 꾸미기

표에 테마 입히기

열린 엑셀 A1:E20 표에 navy 테마 적용해줘

머리글 색, 줄무늬, 테두리를 한 번에 적용합니다. 테마: navy(남색), slate(회색), teal(청록), emerald(초록).

배경색, 굵게

A1:E1 배경 노란색에 굵게 해줘

조건에 맞는 칸만 강조 (조건부 서식)

C2:C100에서 100 이상인 칸을 분홍색으로 강조해줘

조건부 서식으로 넣기 때문에 값이 바뀌면 강조도 자동으로 바뀝니다.

2.6 찾아 바꾸기

열린 엑셀에서 "생산1팀"을 "생산 1팀"으로 모두 바꿔줘

바꾼 칸 수를 알려 줍니다. 수식이 들어 있는 칸의 수식은 보존합니다.

2.7 시트 추가, 칸 병합

열린 엑셀에 "11월" 시트 추가해줘

A1:E1 칸 병합해줘

병합할 칸 중 값이 든 칸이 둘 이상이면 값이 사라질 수 있어 먼저 묻습니다.

2.8 다른 형식으로 저장

열린 엑셀을 C:\업무\제출용.csv 로 저장해줘

열린 엑셀을 PDF로 저장해줘

사본만 저장하고 지금 열린 문서는 그대로 둡니다. 같은 이름이 있으면 새 이름으로 저장합니다.

3. 워드

워드 작업도 지금 보고 있는 문서가 기본입니다. 목차와 장절 읽기는 문서에 "제목 1, 제목 2" 같은 제목 스타일이 있어야 정확합니다.

3.1 읽기: 전체, 목차, 장절, 쪽

목차 보기

이 워드 문서 목차 보여줘

제목마다 수준과 쪽 번호를 알려 줍니다. 제목 스타일이 없는 문서는 "제목 없음(0개)"으로 나옵니다.

특정 장절만 읽기

2.1절 내용만 읽고 요약해줘

그 제목부터 다음 같은 수준의 제목 전까지(하위 절 포함) 읽습니다. 같은 번호로 시작하는 제목이 여럿이면 어느 것인지 묻습니다.

쪽 또는 단락 범위로 읽기

5쪽 내용 보여줘

3쪽부터 7쪽까지 읽고 핵심만 정리해줘

문서 전체 읽기, 분량 확인

열린 워드 문서 전체 읽고 3줄로 요약해줘

이 문서 몇 쪽이고 표와 그림이 몇 개야?

긴 문서를 통째로 읽으면 에이전트의 기억 용량을 많이 씁니다. 가능하면 목차를 먼저 보고 필요한 장절만 읽게 하세요.

3.2 쓰기: 내용, 그림 넣기

문서 끝에 내용 추가

열린 워드 끝에 "## 3. 향후 계획" 제목과 아래 항목 넣어줘. - 11월: 시제품 제작 - 12월: 신뢰성 시험

##는 제목, -는 글머리 항목으로 바뀝니다. 여러 줄 내용은 에이전트가 파일로 만들어 넣습니다.

특정 문구 뒤(앞)에 넣기

"2. 시험 결과" 제목 바로 뒤에 "시험은 KS 기준에 따라 수행하였다." 문장 넣어줘

그 문구가 여러 곳에 있으면 후보를 보여 주고 어느 곳인지 묻습니다.

그림 넣기

C:\업무\그래프.png 그림을 "그림 1" 문구 앞에 넣어줘

표 넣기

열린 워드 끝에 이 표 넣어줘 (항목, 기준, 결과 / 내전압, 1.5kV, 합격 / 절연저항, 100MΩ, 합격)

3.3 찾아 바꾸기

열린 워드에서 "2025년"을 "2026년"으로 모두 바꿔줘

"주의"라는 글자를 모두 굵게 해줘

머리글, 바닥글, 글상자 안의 글도 함께 바꿉니다. 바꾼 개수를 알려 줍니다.

3.4 검토 메모 달기

특정 문구에 메모 하나

"최대 허용 온도 85℃"에 "규격 확인 필요"라고 메모 달아줘

그 문구 자체에 메모를 달고, 다시 읽어 메모가 달렸는지 확인합니다.

여러 메모를 한 번에

7. 문서 검색 (규격·규정 근거 찾기)

PDF 규격서, 한글(HWP) 규정, 워드 보고서, 엑셀 시험표 등을 등록해 두면, 단어를 찾을 때 "어느 파일 몇 쪽, 몇 장 몇 절, 몇 번 항목"인지 근거와 함께 알려 줍니다. Office를 열지 않아도 됩니다.

7.1 등록(캐시)이란

  • 도구가 문서를 한 번 읽어 검색하기 좋은 형태로 따로 저장해 두는 것입니다. 원본 문서는 바뀌지 않습니다.
  • 한 번 등록하면 다음부터는 빠르게 검색합니다. 원본이 바뀌면 검색할 때 자동으로 다시 읽습니다.
  • 지원 형식: PDF, HWP, HWPX, 워드(DOCX), 파워포인트(PPTX), 엑셀(XLSX), CSV, TXT, MD

7.2 폴더나 파일 등록하기

C:\업무\규격서 폴더 문서들 등록해줘

새로 등록한 수, 바뀌어서 다시 읽은 수, 읽지 못한 파일을 알려 줍니다. 파일이 많으면 나눠서 등록하고 이어서 할 명령을 안내합니다.

검색할 때 파일이나 폴더를 함께 알려 주면 등록되지 않은 문서는 그 자리에서 등록하고 검색합니다. 그래서 따로 등록하지 않아도 됩니다.

7.3 파일 하나 읽기, 요약

C:\업무\규격서\KS_C_1234.pdf 1~3쪽 읽고 요약해줘

C:\업무\사내규정.hwp 읽고 출장비 관련 내용만 정리해줘

7.4 검색하기

기본 검색

C:\업무\규격서 폴더에서 "내전압" 찾아서 근거랑 같이 알려줘

항목마다 규격서.pdf p.12, 3. 시험 방법 > 3.2 내전압 (3.2)처럼 파일, 쪽, 장절, 번호를 붙여 알려 줍니다. 표 안의 값은 머리글과 함께(예: 항목: 내전압 | 기준: 1.5 kV 1분) 나옵니다.

여러 단어 함께 / 둘 중 하나

등록된 문서에서 "절연저항 AND 시험" 찾아줘

"방수 OR 방진" 들어간 곳 찾아줘

AND는 둘 다 있는 곳, OR은 둘 중 하나라도 있는 곳입니다. 띄어쓰기, 줄바꿈, 기호는 무시하고 찾기 때문에 SOI 1로 찾아도 SOI #1, SOI-1이 나옵니다. 숫자는 정확히 구분해서 SOI 1이 SOI 10과 섞이지 않습니다.

범위를 좁혀 검색

KS_C_1234.pdf 3~7쪽에서만 "온도" 찾아줘

"시험 방법" 장에서만 "주기" 찾아줘

작성 중인 문서가 규격에 맞는지 확인

열린 워드의 2.1절에 나오는 시험 항목들이 C:\업무\규격서 폴더 규격에 있는지 하나씩 찾아서 근거 알려줘

에이전트가 워드 장절을 읽고, 항목별로 규격서를 검색해 근거를 붙여 답합니다.

검색 결과가 0건이어도 "규격에 없다"고 단정하지 마세요. 글자가 없는 스캔 PDF, 읽지 못한 파일, 아직 등록하지 않은 하위 폴더가 있으면 에이전트가 "검색하지 못한 부분"을 함께 알려 줍니다.

7.5 근거를 엑셀로 저장

방금 검색 결과를 C:\업무\근거_내전압.xlsx 로 정리해줘

지우기 전에 지울 목록을 먼저 보여 주고 "진행할까요?"라고 묻습니다. 원본 문서는 지우지 않습니다. 지운 문서도 다시 검색하면 그때 새로 읽습니다.

7.7 잘 안 되는 경우

  • 스캔한 PDF(그림으로 된 쪽)는 글자가 없어 검색되지 않습니다.
  • 보안(DRM)이 걸린 Office 파일은 등록이 안 될 수 있습니다. 그 파일을 Office로 열어 두고 "열린 워드에서 찾아줘"처럼 요청하세요.
  • HWP, 엑셀, CSV는 쪽 정보가 없어 쪽 대신 장절이나 행 위치(예: 매출!12행)로 근거를 알려 줍니다.

같은 이름의 파일이 있거나 열려 있어서 새 이름(시각이 붙은 이름)으로 저장한 것입니다. 에이전트가 알려 준 실제 경로를 확인하세요. 기존 파일을 바꾸고 싶으면 "덮어써줘"라고 분명히 말해야 합니다.

에이전트가 같은 말을 반복하거나 이상한 글자를 계속 써요.

대화가 너무 길어진 경우가 많습니다. 새 대화를 열고 다시 요청하세요.

에이전트가 직접 파이썬 코드를 짜려고 해요.

"office-cli 스킬로만 해줘"라고 말해 주세요. 도구를 쓰면 저장 후 확인, 되돌리기 지점, 덮어쓰기 방지가 함께 됩니다.

메일이 자동으로 나가지 않을까 걱정돼요.

"보내줘"라고 분명히 요청하지 않으면 작성 창만 뜹니다.

검색 결과가 하나도 없어요.

검색어를 짧게 줄이거나(예: "내전압 시험" -> "내전압"), OR로 비슷한 말을 함께 찾아보세요. 스캔 PDF는 검색되지 않습니다.

11. 베타테스트 피드백 보내는 법

잘 안 된 경우 아래 네 가지를 함께 보내 주시면 원인을 빨리 찾을 수 있습니다.

  1. 입력한 요청 문장 (그대로 복사)
  2. 에이전트의 마지막 답변 (그대로 복사)
  3. 기대한 결과와 실제 결과의 차이 (한두 줄)
  4. 가능하면 대화 내보내기 파일

도구가 실패한 기록은 C:\CLI\office-cli\data\logs\errors.txt에 자동으로 남습니다. 이 파일을 함께 보내 주셔도 좋습니다. 문서 내용은 기록되지 않고 실행한 명령과 오류만 남습니다.
