ml-kit 사용 가이드

엑셀 데이터로 예측 모델을 만들고, 새 조건의 결과를 예측하고, 보고서를 만드는 방법 | 베타테스트용 | ml-kit 2.4.2

ml-kit은 엑셀이나 CSV로 모아 둔 과거 데이터에서 규칙을 스스로 배워, 새로운 조건에서 결과가 어떻게 될지 예측하는 도구입니다. 통계나 프로그래밍을 몰라도 됩니다. AI 에이전트(Gemma)에게 "이 파일로 수율 예측 모델 만들어줘"처럼 말하면, 도구가 데이터 정리부터 모델 비교, 결과 확인, 보고서 작성까지 알아서 합니다. 각 사례의 요청 예시 옆 "복사" 버튼을 눌러 그대로 붙여 넣고, 파일 경로와 컬럼 이름만 내 데이터에 맞게 바꿔 쓰세요.

1. 시작하기

1.1 예측 모델이란 (쉽게)

예를 들어 공정 기록이 이렇게 쌓여 있다고 해 봅시다.

반응온도(°C)압축압력(bar)촉매비율(wt%)수분함량(%)생산효율(%)
1823.12.41.287.5
1752.82.90.989.1
1903.42.11.584.3
... 수백 행 ...

ml-kit은 이 표를 보고 "온도, 압력, 촉매, 수분이 이럴 때 생산효율이 이 정도"라는 관계를 배웁니다. 그러면 아직 해 보지 않은 조건(예: 온도 180, 압력 3.0, 촉매 2.5, 수분 1.0)에서 생산효율이 얼마일지 미리 계산할 수 있습니다.

1.2 ml-kit으로 할 수 있는 일

모델 만들기

데이터 파일과 타겟만 알려 주면 5가지 방식의 모델을 경쟁시켜 가장 잘 맞히는 것을 고릅니다.

성능 높이기

"성능 올려봐"라고 하면 도구가 개선 방법을 제안하고 다시 학습해 점수 변화를 알려 줍니다.

예측하기

조건 한 건을 말로 넣거나, 새 조건이 여러 행 든 엑셀 파일을 통째로 예측합니다. 예측 범위도 함께 줍니다.

보고서 만들기

판정(적합/조건부/부적합), 성능 그래프, 영향 큰 피처, 파생변수 계산식이 담긴 워드 보고서를 만듭니다.

경고 받기

학습 범위를 벗어난 입력, 처음 보는 종류, 빈 값, 확신이 낮은 예측을 알려 줍니다.

기록 관리

모든 학습 기록이 버전별로 남아, 가장 좋았던 조건을 도구가 찾아 씁니다.

1.3 준비: OpenCode와 Gemma

  1. OpenCode를 열고 화면 아래 모델 이름이 Gemma인지 확인합니다.
  2. 새 대화로 시작합니다. 입력창에 /new. 데이터 파일이나 주제가 바뀌면 새 대화를 여세요.
  3. 데이터 파일의 전체 경로를 준비합니다. 탐색기에서 파일을 오른쪽 클릭하고 "경로로 복사"(또는 Ctrl+Shift+C).
  4. 요청하고 기다립니다. 학습은 데이터 크기에 따라 몇십 초에서 몇 분 걸립니다. 기다리는 동안 다른 일을 해도 됩니다.

학습 결과는 데이터 파일 옆에 <데이터파일이름>_ml_data 폴더로 저장됩니다. 이 폴더를 지우면 학습 기록과 모델이 모두 사라지니 지우지 마세요.

2. 데이터 준비

2.1 이런 모양이면 됩니다

  • 한 행 = 한 건(한 번의 생산, 한 개의 제품, 하루의 기록), 한 열 = 한 항목인 표.
  • 파일 형식: 엑셀(.xlsx) 또는 CSV.
  • 머리글이 1행이 아니어도 됩니다. 보고서 형식처럼 위에 제목, 결재란, 빈 행이 있어도 도구가 머리글을 찾습니다. 단위 행이 따로 있으면 알려 주세요(2.3).
  • 빈 칸이 조금 있어도 됩니다. 피처의 빈 칸은 자동으로 채우고, 타겟이 빈 행은 학습에서 뺍니다.
  • 날짜 열, 글자 열(라인, 설비, 작업자)도 피처로 쓸 수 있습니다. 날짜는 연·월·요일·시각으로 나눠 씁니다.

행이 많을수록, 결과에 실제로 영향을 주는 열이 들어 있을수록 예측이 정확해집니다. 수십 행으로도 학습은 되지만 점수가 낮게 나올 수 있습니다.

결과를 보고 나서 정해지는 값예측할 때는 알 수 없는 값이라 실제로 쓸 수 없는 모델이 됨검사 후 판정 메모, 재작업 여부
타겟을 계산해 만든 값답을 미리 보여 주는 셈생산효율을 맞힐 때의 "효율등급"

4. 결과 읽는 법

4.1 점수와 판정

점수판정뜻
0.90 이상적합예측에 바로 쓸 수 있는 수준
0.70 ~ 0.90조건부경향을 보거나 참고용으로는 쓸 만함. 개선을 권장
0.70 미만부적합지금 데이터로는 잘 맞히지 못함. 데이터나 피처 보강이 필요
  • 회귀 점수(R², 설명력): 결과값의 변화를 피처가 얼마나 설명하는지. 1이면 완벽, 0이면 평균값으로 찍는 것과 같은 수준.
  • 분류 점수(Macro-F1): 등급마다 맞힌 정도를 고르게 평균한 값. 불량처럼 드문 등급을 못 맞히면 점수가 낮아집니다.
  • 점수는 학습에 쓰지 않은 데이터로 시험한 점수입니다. 데이터를 5조각으로 나눠, 4조각으로 배우고 나머지 1조각으로 시험하기를 5번 반복한 평균입니다. 그래서 실제 예측 실력에 가깝습니다.
  • 학습 데이터에서만 점수가 아주 높고 시험 점수와 차이가 크면(0.15 넘게), 점수가 높아도 "조건부"로 판정합니다. 외워서 맞히는 상태일 수 있기 때문입니다.

5. 성능 높이기

성능 더 올려봐

점수가 0.90 이상이면 "이미 목표를 달성했다"고 알리고 멈춥니다. 그보다 낮으면 도구가 제안한 방법으로 다시 학습하고 점수 변화를 알려 줍니다. 최대 5번까지 반복합니다.

도구가 시도하는 방법

  • 영향이 거의 없는 피처 빼기: 기여도 1% 이하인 입력을 빼고 다시 학습합니다. 잡음이 줄어 점수가 오르기도 합니다.
  • 파생변수 추가: 영향이 큰 두 입력을 곱한 새 변수(예: 반응온도x촉매비율)를 만들어 함께 학습합니다. 두 조건이 함께 작용하는 효과를 잡을 수 있습니다. 보고서의 "2.1 파생변수"에 계산식이 나옵니다.

도구의 제안을 다 해 봐도 점수가 낮다면 데이터 쪽을 보강해야 합니다. 행을 더 모으거나, 결과에 영향을 줄 만한 항목(원료 로트, 설비, 작업 조건)을 열로 추가해 보세요.

범위(pred_lo ~ pred_hi)는 어떻게 쓰나요?

  • 범위가 좁을수록 모델이 정밀하다는 뜻입니다.
  • 실제 값이 범위 밖으로 나오는 일도 약 10%는 있습니다. 범위 밖이라고 바로 이상은 아니지만, 자주 벗어나면 공정이나 데이터가 학습 때와 달라졌을 수 있습니다.
  • 규격 판단에 쓸 때는 예측값뿐 아니라 범위의 끝(예: pred_lo가 하한 규격 위인지)도 함께 보세요.

9. 자주 묻는 질문과 문제 해결

"컬럼을 찾을 수 없습니다"라고 나와요.

이름이 조금 다를 때(띄어쓰기, 대소문자)는 도구가 맞는 이름을 추천하고 에이전트가 한 번 다시 실행합니다. 그래도 안 되면 "컬럼 이름부터 보여줘"로 정확한 이름을 확인하세요. 머리글이 1행이 아닌 파일이면 몇 행인지 알려 주세요.

"ID 같은 컬럼"이라며 멈췄어요.

종류가 너무 많은 글자 열(일련번호, 로트 번호 등)은 피처로 쓸 수 없습니다. 그 열을 빼고 다시 요청하세요.

점수가 0.5도 안 나와요.

"성능 더 올려봐"를 먼저 해 보세요. 그래도 낮으면 결과에 영향을 주는 항목이 데이터에 없거나, 행이 부족한 경우가 많습니다. 공정 담당자와 함께 빠진 요인이 있는지 살펴보세요.

학습이 너무 오래 걸려요.

수만 행 데이터는 몇 분 걸릴 수 있습니다. 에이전트가 기다리는 중이니 대화를 끊지 마세요. 10분이 넘으면 피드백으로 알려 주세요.

같은 버전 이름으로 다시 학습하고 싶어요.

기존 결과를 지우지 않도록 도구가 새 버전으로 저장하자고 합니다. 꼭 바꿔야 하면 "v1을 덮어써줘"라고 분명히 말하세요.

내가 정한 계산식으로 파생변수를 만들고 싶어요.

베타 버전에서는 도구가 제안하는 파생변수(영향 큰 두 입력의 곱)만 에이전트가 쓸 수 있습니다. 특정 계산식이 필요하면 피드백으로 알려 주세요. 원하는 계산식을 엑셀에서 열로 만들어 두고 피처로 넣는 방법도 있습니다.

CSV를 엑셀로 열면 한글이 깨져요.

도구가 저장하는 CSV는 엑셀에서 바로 열리도록 한글 인코딩을 맞춥니다. 다른 프로그램에서 만든 CSV가 깨지면 엑셀의 "데이터 > 텍스트/CSV"로 불러오며 인코딩을 UTF-8로 고르세요.

에이전트가 같은 말을 반복하거나 이상한 글자를 계속 써요.

대화가 길어진 경우가 많습니다. /new로 새 대화를 열고, 데이터 파일 경로를 다시 알려 주며 이어서 요청하세요. 학습 기록은 파일로 남아 있어 사라지지 않습니다.
