# 실기 테스트: ml-kit 2.5.0~2.9.0, office-cli 1.4.3, 구조 정리 (2026-10-30)

PR #26 이후 추가된 기능을 회사 PC(Windows 11, Office 16, 문서 보안)에서 확인합니다.
요청 문장은 OpenCode(Gemma)에 그대로 입력합니다. 판정은 화면에 보이는 것(실행한 명령, 마지막 답변, 만들어진 파일)으로 합니다.
결과는 아래 "결과 기록" 표를 채워 `docs/test_logs/`에 올려 주세요.

## 0. 준비 (15분)
1. `C:\CLI`를 이 저장소의 `CLI` 폴더로 통째로 바꿉니다. 바꾼 뒤 아래만 있어야 합니다.
   - `C:\CLI\ml-kit`: `ml_train.py`, `ml_predict.py`, `ml_report.py`, `ml_map.py`, `ml_export.py`, `SKILL.md` (실행 후 `data\` 폴더가 생기는 것은 정상)
   - `C:\CLI\office-cli`: `excel.py`, `word.py`, `ppt.py`, `outlook.py`, `reader.py`, `office.py`, `_runtime.py`, `_office.py`, `SKILL.md`
2. 실기 러너가 필요하면 `CLI-dev` 폴더를 `C:\CLI-dev`로 복사합니다 (`C:\CLI`와 나란히).
3. OpenCode 스킬 폴더의 `ml-kit\SKILL.md`, `office-cli\SKILL.md`를 새 파일로 덮어쓰고, 전역 지침을 `docs/opencode/AGENTS.md`로 바꾼 뒤 OpenCode를 다시 시작합니다.
4. 시험 폴더 `C:\ml_beta`를 만들고 아래 파일을 둡니다.
   - `공정.xlsx`: 실제 공정 데이터 (머리글·단위 행이 있는 보고서형이면 더 좋음). 이상치처럼 보이는 행이 몇 개 있으면 좋음
   - `맵.xlsx`: A열 0~100을 5 단위, B·C열에 그 값에 따른 숫자가 있는 표 (직접 만들어도 됨)

## B. 이상치 자동 제외와 점수 용어 (ml-kit 2.5.0, 15분)
`공정.xlsx`에 "제외" 열을 추가하고, 한 행에 `센서오류`, 이상해 보이지만 실제인 한 행에 `포함`을 적어 저장합니다.

| # | 요청 | 통과 기준 |
|---|---|---|
| B1 | `C:\ml_beta\공정.xlsx 로 <타겟> 예측 모델 만들어줘. 피처는 <입력들>` | 답에 학습 제외 행 수(직접/자동), "검증 R2(제외 행 포함)"이 나옴. "제외" 열은 피처로 쓰이지 않음 |
| B2 | `<데이터>_ml_data\v1\excluded_rows.xlsx` 열기 | `원본 행`이 엑셀 행 번호와 일치, `센서오류` 행은 "직접 표시", `포함` 행은 목록에 없음 |
| B3 | 원본 `공정.xlsx` 다시 열기 | 도구가 고친 흔적 없음 |
| B4 | `보고서 만들어줘` | 요약 표에 "검증 R² (제외 행 미포함)", "검증 R² (제외 행 포함)" 두 열, 판정 기준 줄에 학습/검증 용어 설명, 실측 대비 예측 그림에 주황색 X |

## F. 성능예측표 (ml_export, 2.9.0, 20분)
| # | 요청 / 할 일 | 통과 기준 |
|---|---|---|
| F1 | `<데이터>_ml_data\v1 모델로 성능예측표 만들어줘` | Gemma가 데이터 설명을 짧은 제목으로 정리해 `--title`로 넘김. 몇 분 뒤 남긴 입력/뺀 입력, 검증 R², 표 행 수를 알림 |

| F3 | `<입력>은 꼭 넣어서 성능예측표 다시 만들어줘` | `--keep` 사용, 그 입력이 남음 |

| F5 | 노란 칸 값 바꾸기 / 노란 칸 아닌 곳 고치기 / 노란 칸에 글자 입력 | 값이 바로 다시 계산됨 / 보호 안내가 뜨고 고쳐지지 않음 / "숫자만 입력" 경고 |
| F6 | 노란 칸에 학습 범위 밖 값 | 상태·판단 칸이 주황색 "범위 밖", "참고용 (학습 범위 밖)" |

| F8 | 시트 탭 오른쪽 클릭 (삭제·이름 바꾸기) | 할 수 없음 |
| F9 | 정보 시트 | "원래 모델"이 `<데이터>_ml_data\v1`처럼 끝부분만, 사용자 이름이 든 전체 경로 없음 |
| F10 | 같은 예측 조건으로 D1의 `ml_predict` 값과 계산기 값 비교 | 차이가 정확도 시트의 표 보간 오차 수준 |
| F11 | 문서 보안 아래 저장된 엑셀을 다른 사람 PC(파이썬 없음)에서 열기 | 열리고 계산됨 |
| F12 | 출력 여러 개로 학습한 버전으로 F1 | 출력마다 다른 입력이 남을 수 있고, 계산기는 모든 입력을 합쳐 받으며 출력은 학습 순서대로 |
