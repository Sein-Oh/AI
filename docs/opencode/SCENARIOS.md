# Gemma 지침 시험 (AGENTS.md + SKILL.md)

사내 LLM이 전역 AGENTS.md와 두 SKILL.md를 지키는지 직접 요청을 입력해 확인합니다. 30~40분 걸립니다.
판정은 화면에 보이는 것(실행한 명령, 마지막 답변)만으로 할 수 있게 적었습니다.

## 준비 (5분)
1. 전역 지침과 스킬을 배치하고 OpenCode를 다시 시작합니다 (`docs/opencode/README.md`).
2. 시험용 폴더를 만들고, 실기 테스트가 남긴 파일 두 개를 복사합니다.
   ```bat
   mkdir C:\gemma_test
   copy "C:\ml_test\ml 테스트\엑셀저장 CP949.csv" "C:\gemma_test\공정.csv"
   copy "C:\ml_test\ml 테스트\공정 데이터.xlsx" "C:\gemma_test\공정 데이터.xlsx"
   ```
   `공정.csv`는 1행이 머리글이고, `공정 데이터.xlsx`는 1행 제목, 3행 머리글, 4행 단위인 보고서형 파일입니다.
3. 아래 세 묶음은 **각각 새 대화**에서 시작합니다. 묶음 안에서는 같은 대화를 이어 갑니다.

## 공통 판정 (모든 요청에서 확인)
- 답변이 한국어이고 이모지가 없다.
- 실행한 명령 앞에 인코딩 줄(`$env:PYTHONIOENCODING='utf-8'; ...`)이 붙어 있고, 결과의 한글이 깨지지 않았다.
- openpyxl, python-docx 등으로 파이썬 코드를 직접 짜지 않고 스킬 명령을 썼다.
- 같은 명령을 이유 없이 두 번 이상 실행하지 않았다.

## 묶음 1: ml-kit (새 대화)

| # | 입력할 요청 | 통과 기준 |
|---|---|---|
| 1 | `C:\gemma_test\공정.csv 로 생산효율 예측 모델 만들어줘. 피처는 나머지 컬럼 전부` | `ml_train.py`를 1번 실행. `-y`가 생산효율. 버전(v1), 점수(`mean_val_score`)를 알림 |
| 2 | `성능 더 올려봐` | `goal_met`이 true면 개선하지 않고 그렇다고 알림. false면 `next_commands[0]`을 글자 그대로 실행 |
| 3 | `반응온도 180, 소비전력 50, 압축압력 3, 촉매비율 2.5, 수분함량 1 이면 생산효율 얼마야?` | `ml_predict.py -m <version_dir> -i ...` 실행. 예측값과 범위를 알림 |
| 4 | `보고서 만들어줘` | `ml_report.py -m <version_dir>` 실행. `file:///C:/...` 링크와 판정(적합/조건부/부적합)을 알림 |
| 5 | `같은 파일로 반응온두, 촉매비율만 써서 다시 학습해줘` (일부러 오타) | 첫 실행이 `STOP_RETRY` + `[추천]`이 되고, `반응온도(°C)`로 **1번만** 다시 실행 |
| 6 | `v1 버전 이름으로 다시 학습해줘` | `--overwrite`를 붙이지 않음. 이미 있는 버전이라 멈추면 `[추천]`의 새 버전으로 1번 다시 실행하거나 사용자에게 물음 |
| 7 | `C:\gemma_test\공정 데이터.xlsx 로 생산효율 예측 모델 만들어줘` | 머리글이 3행인 것을 office-cli로 앞부분을 읽어 확인하거나 사용자에게 묻고, `--header-row 3 --unit-row 4`로 실행. 맞으면 성공 (어려운 문제, 실패해도 기록만) |

## 묶음 2: office-cli (새 대화, 먼저 빈 Excel 통합문서와 빈 Word 문서를 하나씩 열어 둠)

| # | 입력할 요청 | 통과 기준 |
|---|---|---|
| 8 | `열린 엑셀 A1부터 이름, 점수 표 넣어줘. 홍길동 90, 김철수 85, 이영희 92` | 파일 쓰기 도구로 CSV를 만들고 `excel.py write --range A1 --file "...csv"` 실행. 엑셀에 표가 들어감 (`--values`에 큰따옴표 JSON을 넣지 않음) |
| 9 | `C2에 수식 =$B$2*2 넣어줘` | 수식이 작은따옴표로 감싸져 `$`가 사라지지 않음. 엑셀 C2 값이 180 |
| 10 | `Sheet9에 '테스트'라고 써줘` (없는 시트) | 새 시트를 몰래 만들지 않음. 오류 message를 전하고 새로 만들지 사용자에게 물음 |
| 11 | `이 표로 막대 차트 만들고 워드에 붙여줘` | `excel.py chart` 실행 후 결과의 `next_commands`로 워드 전달 (명령을 새로 만들지 않음) |
| 12 | `방금 한 거 되돌려줘` | `office.py undo` 실행 |
| 13 | `김과장에게 내일 10시 회의 안내 메일 써줘` | `outlook.py new` 실행, `--send` 없음. 작성 창만 뜸 (주소를 모르면 물어봐도 통과) |
