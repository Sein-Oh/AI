# 눈 확인 결과 (집 PC, Office 2007, 2026-10-31)

대상: ml-kit 2.9.10으로 만든 성능예측표와 보고서. 실제 Excel·Word 2007에서 자동으로 값을 넣고 읽어 확인했고, 계산기 시트는 그림으로 저장해 색을 봤습니다.

| 항목 | 결과 | 확인한 내용 |
|---|---|---|
| V1 | O | 사용자가 먼저 확인, 계산기 그림에서 재확인 |
| V2 | O | 입력을 바꾸면 예측값이 75.66 -> 75.62로 다시 계산됨 |
| V3 | O | 잠긴 칸 쓰기 차단, 입력 칸은 숫자 검사와 "숫자만 입력할 수 있습니다." 안내. 경고 창 표시는 자동으로 못 봄 |
| V4 | O | 범위 밖 입력: 주황 "범위 밖", "참고용 (학습 범위 밖)". 범위 안: 초록 "정상" |
| V5 | O | 일괄계산 3~5행 입력 -> 예측값, 하한·상한, 판단 표시 |
| V6 | O | 시트 삭제 차단, 통합문서 구조 잠금, `표_` 시트 3개 veryHidden |
| V7 | O | 일치도 있음, 원래 모델은 `공정_다중출력_ml_data\v2`로 끝부분만, 전체 경로 없음 |
| V8 | - | 회사 PC 몫 |
| V9 | O | Word 2007에서 열림 (표 14개, 6쪽), 제외 행 미포함/포함, 성능예측표 문단과 일치도, 그림에 주황 X와 "학습 제외 행 (14)" |
| V10 | 일부 | 두 가이드의 목차 링크 깨짐 0건, ml-kit 가이드 "복사" 버튼 동작. "찾기" 결과와 스크롤은 미확인 |

참고: 처음 사용자가 연 보고서는 수정 전 2.9.8로 만든 파일이라 Word 2007에서 열리지 않았습니다. 2.9.9 이후 다시 만든 보고서는 열립니다.
